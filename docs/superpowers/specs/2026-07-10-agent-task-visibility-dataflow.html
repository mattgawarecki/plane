Why the reducer is the center of gravity

Both clients (web now, native later) wrap the same pure functions. No React, no MobX, no DOM — so the highest-value tests live in the package and cover every client at once.

Two entry points feed it: applyEvent from the Push lane, reconcile from the Pull lane. State is never authoritative locally — it's always rebuildable from a snapshot + the stream.
